## The title

> Chief Penguin Relocation Officer

A real-sounding corporate title with one hilariously specific twist:
32 characters, nothing else.

## How it works

`main.py` (pure Python 3.13 stdlib, no dependencies) writes the single job
title to `/output/entry.txt`. The blind judge then compares it two at a time
against the other entries and picks the weirder, funnier one.

## Run locally

```sh
python3 main.py
```

This writes the title to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`
when that variable is set).
